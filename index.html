☁️ Google Colab Setup

Use Google Colab's free GPU for faster training.

📋 How to Use Colab

Step 1: Open the modified BeatriceV2_Trainer_Notebook.ipynb in Google Colab.

Step 2: Run the "Install Modules" cell to set up the environment.

Step 3: In the "Upload Your Dataset" cell, upload a ZIP of your WAV files.

Step 4: Set your speaker name and run the cell.

Step 5: Run the "Settings" cell to start the training UI.

Step 6: Download the trained model from the output/ folder.

⚠️ Important Notes

• The Colab notebook has been modified to remove the default HuggingFace dataset.

• You must upload your own WAV dataset as a ZIP file.

• Audio should ideally be 16kHz mono WAV format for best results.

• Colab's free T4 GPU is significantly faster than Mac CPU/MPS training.

• Training typically takes 30–90 minutes on a T4 GPU for 10K steps.
